# رفيق 🦅

**يوتيوب آمن للأطفال (5–12 سنة) بمقصّ ذكي يحذف اللحظة غير المناسبة، لا المقطع كاملاً.**

🌐 **جرّبه الحين:** [rafeeq-kids.netlify.app](https://rafeeq-kids.netlify.app)

## وش يسوي رفيق؟

- **المقص الذكي:** نموذج ذكاء اصطناعي (Gemini) يشاهد المقطع بالصوت والصورة، ويحدد اللحظات غير المناسبة لعمر الطفل؛ فيكتم الكلمة ويتخطى المشهد، ويكمل المقطع.
- **حجب كلي عند الحاجة:** المقطع غير المناسب كلياً يُخفى من النتائج.
- **بطاقات حوار للأهل:** كل لحظة مقصوصة تتحول إلى سؤال يفتح حواراً هادئاً مع الطفل.
- **الخصوصية أولاً:** لا حسابات ولا قاعدة بيانات؛ بيانات الأسرة تبقى على جهازها.
